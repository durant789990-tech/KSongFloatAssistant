# 全民 K 歌自动化引流工具 - 项目需求与技术设计文档

## 一、 项目概述

本项目旨在开发一款运行在 Android 端的原生自动化辅助工具。通过结合 Android 系统的无障碍服务（Accessibility Service）与大语言模型 API（如 DeepSeek），实现精准匹配同城/附近用户、智能分析用户作品并自动进行互动（关注、评歌、私信）的自动化引流流程。

---

## 二、 核心功能模块

### 1. 设备与权限管理
* **无障碍服务激活**：引导用户开启 Android `AccessibilityService` 权限。
* **悬浮窗控制面板**：在系统顶层提供控制悬浮窗，用于实时显示运行状态、日志（Log）以及一键暂停/停止运行。

### 2. 自动化探索与定位
* **同城/附近人扫描**：自动打开全民 K 歌“同城/附近”列表，逐个遍历用户卡片。
* **主页信息提取**：进入用户主页后，自动抓取用户名、签名、最新发布的作品名称等节点文本信息。

### 3. AI 智能交互生成
* **上下文分析**：将抓取到的“歌曲名称/动态文本/用户特征”组装为特定的 Prompt。
* **DeepSeek API 接入**：调用大模型生成带有拟人化口吻、自然且不含营销敏感词的赞美短评或私信文本。

### 4. 自动互动执行
* **关注与点赞**：自动触发页面“关注”等互动控件。
* **评论与私信**：将 AI 生成的文本自动粘贴/输入至对应的评论框或私信框并提交。
* **循环与跳转**：完成单个用户的互动后自动返回列表页，滑动寻找下一个目标。

## 三、 技术选型与架构

### 1. 应用形态
* **应用类型**：Android 原生应用（原生 `.apk`）
* **开发语言**：Kotlin 或 Java
* **开发 IDE**：Android Studio / Cursor

### 2. 核心技术栈
| 模块 | 技术方案 | 作用 |
| --- | --- | --- |
| **自动化控制** | Android `AccessibilityService` | 监听 UI 界面变化，捕获控件节点，执行模拟点击与输入 |
| **网络请求** | OkHttp / Retrofit | 与 DeepSeek API 进行 HTTP POST 通信 |
| **界面展示** | Material Design / WindowManager | 构建配置界面与运行时的悬浮日志窗 |
| **大模型 API** | DeepSeek V3 / R1 | 生成拟人化、高相关度的互动文本 |

## 五、 技术难点与风控应对策略

### 1. 拟人化行为（规避自动化检测）
* **随机延迟**：每次点击与页面滑动之间加入随机等待时间（如 2~5 秒），避免固定频率触发平台警报。
* **坐标与轨迹**：对于屏幕滑动，采用带有曲线偏移的模拟轨迹，而非瞬间直线滑动。

### 2. 文本风控与质量控制
* **提示词约束（Prompt Engineering）**：
  * 限制单句字数在 15 字以内。
  * 严禁包含“加微”、“私聊”等敏感营销词汇。
  * 强制设定“自然听众”、“夸奖为主”的人设语气。
* **本地词库预筛**：在发送私信/评论前，使用本地正则匹配剔除可能触发屏蔽的敏感词。

### 3. UI 节点稳定性
* **动态定位**：优先通过 `text`、`content-description` 或控件结构树定位，避免使用写死的屏幕像素坐标（防止不同手机分辨率导致失效）。

## 七、 首次授权顺序

1. 打开应用首页，完成权限向导。
2. 授权悬浮窗权限。
3. 启用无障碍服务 `KSongFloatAssistant`。
4. Android 13+ 授权通知权限。
5. 在 AI 设置页配置 DeepSeek Base URL（如 `https://api.deepseek.com`）、模型（如 `deepseek-chat`）和 API Key。
6. 打开全民 K 歌，手动进入「同城/附近」列表。
7. 启动悬浮助手，点击「开始自动引流」。

目标包名默认：`com.tencent.karaoke`
